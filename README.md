# Лендинг ANDROS Professional — партнёрам

Файлы:
- `index.html` — главная страница (лендинг), все картинки встроены внутрь файла
- `spasibo.html` — страница благодарности, на неё форма перекидывает после заявки
- `google-apps-script.gs` — код для приёма заявок в Google Таблицу

## Как опубликовать на GitHub Pages
1. Создайте новый репозиторий на github.com (публичный).
2. Add file → Upload files → перетащите все файлы из этой папки → Commit changes.
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Чтобы заявки приходили
GitHub Pages — статичный хостинг, сам он заявки не принимает.
1. Настройте Google Таблицу по инструкции в `google-apps-script.gs`.
2. В `index.html` найдите строку `var LEAD_ENDPOINT='';` и вставьте между кавычками URL веб-приложения.
3. Отправьте тестовую заявку и проверьте, что строка появилась в таблице.

## Meta Pixel
Код пикселя вставьте в `<head>` обеих страниц, а событие `fbq('track','Lead')` — только в `spasibo.html`.
